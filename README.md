# Sleep-Stress-Analysis
**Project Overview:**
This project analyzes the relationship between sleep habits, stress levels, and lifestyle factors using survey data collected through a google form.

**Objective** 
*Understand how sleep duration relates to stress levels.
*Compare stress levels across different workout frequencies.
*Identify patterns between lifestyle habits and stress.

**Dataset**
Source: Self-creates google form survey
Total response: 37
Data types: Survey data

**Tools used**
SQL (Data Cleaning and analysis)
Excel (Charts and visualization)
Data Type: Survey data

**Analysis Perfomed**
Average stress level by sleep hours
Average stress level by workout frequency
Comparison of different lifestyle factors
Data cleaning and aggregation using SQL

**Key Findings**
Sleep duration showed variation in average stress levels.
Stress levels differed among workout groups.
Lifestyle habits appeared to infulence reported stress.
